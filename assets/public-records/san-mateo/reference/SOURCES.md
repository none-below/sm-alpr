# San Mateo — reference documents

Public City of San Mateo council records and Axon's published standard terms, collected 2026-10-22 for the
Axon ALPR amendment (Oct 5, 2026, item 12). Not covered here: `Policy_463_ALPR_2025-12-23.pdf` and
`SOP_205_ALPR_2026-03-06.pdf`, which were added earlier (see `git log` for this folder).

How the City's files were fetched:
- **PrimeGov item attachments** download with plain curl from
  `https://sanmateo.primegov.com/api/compilemeetingattachmenthistory/historyattachment/?historyId=<uuid>`. The uuid is
  taken from the meeting's HTML agenda, `https://sanmateo.primegov.com/Portal/Meeting?meetingTemplateId=<agenda id>`.
- **Compiled packets and minutes** (`/Public/CompiledDocument?meetingTemplateId=<id>&compileOutputType=1`) redirect
  to a signed `pgwest.blob.core.windows.net` URL that expires after about 48 hours. Cite the CompiledDocument URL, not
  the blob URL.
- **Page extracts** were made with `qpdf --empty --pages <in> <ranges> -- <out>`. "Source pages" are the packet's
  own page numbers (its "N of M" footers).

The date in each filename is the date named in the "Filename date" column.
