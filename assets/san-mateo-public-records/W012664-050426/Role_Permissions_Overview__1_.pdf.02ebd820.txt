Role Permissions Overview
When creating roles, permissions are assigned that define what users in that role can see and do. This article
explains what each permission does so Admins can configure roles that match user responsibilities and their
organization’s policies.

Question
Answer
When Admins create or edit a role in Flock, they assign Networks and Permissions to ensure users in that role
have the appropriate access. Each role clearly identifies the type of access it provides to Flock features.
For instructions on creating, editing, or deleting roles, please view the How to Manage Roles
(https://help.flocksafety.com/s/article/How-to-Manage-Roles) article.
Permissions
User must be an Admin with permissions to edit roles and permissions enabled.
Accessing Role Permissions
To access permissions for a role: 
Open the Roles sub-tab of the Admin page from the green navigation bar 
Click into an existing role or select '+ Add New Role' to view the permissions 
On the role configuration page, scroll down to the Permissions section to enable or disable feature
access for that role. Depending on what Flock package the Admin's organization has, some of these
features may be visible or greyed out. If it is greyed out, it means the organization does not have
access to those features at this time.

Understanding Feature Permissions 
Each permission controls access to a specific feature or area in the Flock system. Use the list below to understand
what each permission does before enabling it for a role. 'LE Only' indicates features only available to law
enforcement agencies.
Admin
Admin: Allows those assigned to access the Admin page to edit roles, users, Networks, etc.
Edit Organization Details: User can access and edit organization details within Admin 
Allows those assigned to access the Organization page and edit organization location,
enable/disable Lookup, enable Multi-Factor Authentication, etc. 
Manage Billing & Invoices: User can access and edit billing data within the Admin Billing tab 
Share Networks: User can access the Sharing tab on the main navigation
Use File Validator (LE Only): User can access and run file validation
Edit User Profile Settings: User can edit personal details including name, title, and phone number
within User Profile 
Search
Search: Users can access and conduct investigative Searches 
Access Statewide or Nationwide Networks (LE Only): User can execute a Search or Lookup across
statewide or nationwide Networks
Visual Search: User can access Visual Search as an advanced option within Search

VMS-Specific Rule
VMS permissions are governed by both the role and Network. For VMS to be enabled on the network: 
The role must have VMS permissions enabled
The Network must have approved VMS access
If a role has VMS permissions enabled but a user still cannot select VMS for a Network, visit the Network page to
confirm that the network is enabled. If the network is enabled and VMS remains unavailable, VMS was not
approved for shared access on that Network.
