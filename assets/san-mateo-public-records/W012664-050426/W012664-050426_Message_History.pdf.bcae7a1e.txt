Thank you for your interest in public records of the City of San Mateo.  Your request was received by the City

Record(s) Requested: Pursuant to the California Public Records Act (Gov. Code § 7920.000 et seq.), I 
request the following records from the San Mateo Police Department.
This request seeks existing records only (Gov. Code § 7922.530; Sierra Club v. Superior Court (2013) 57 
Cal.4th 157).
Context. On April 28, 2026, in response to PRA W012570-041926, SMPD produced a Flock platform 
event log ("SMPD4.20.2026_EVENTLOG") reflecting two events involving "Receiving Organization: 
University of the Pacific (CA)":
- Event ID 7ede5f4e-4f97-56dc-9357-4b92d3904374 — 2026-02-12 04:51:19.301Z — create networkShare 
— Permissions: feedView (User: Phoenix O'Rourke)
- Event ID 5469f801-e05e-5c39-ace6-0ce9abf1106a — 2026-02-28 04:09:40.789Z — delete networkShare 
— Permissions: Search, VMS, Hotlist (User: Steve Casazza)
On the face of the produced log, the Feb 12 create (feedView) has no corresponding delete event, and the 
Feb 28 delete (Search, VMS, Hotlist) has no corresponding create event. The literal reading is that a 
feedView share to University of the Pacific was created on Feb 12 and was never removed. An alternative
reading is that the two events describe the same share whose permissions were modified between Feb 12 
and Feb 28, in which case any modification events would also be responsive to PRA W012570-041926. I'd 
like to resolve which reading is correct and confirm the current state of any sharing relationship with 
University of the Pacific.
Scope of records. As established in W012570-041926, this request reaches records held by Flock Safety 
as SMPD's agent or contractor, or otherwise accessible to SMPD through its Flock account. SMPD's

Master Services Agreement § 4.1, SMPD Policy 463 (§§ 463.2, 463.5), and SMPD SOP 205.5.1 each 
confirm that platform records concerning SMPD's data and sharing configuration are SMPD records 
within the meaning of Gov. Code § 7920.530, regardless of which server they reside on. SMPD has

Records requested:
1. The current state of any networkShare records, network sharing entitlements, or equivalent data-
sharing relationships between SMPD and University of the Pacific (CA) on the Flock Safety platform — 
for each, its identifier, permission scope, and creation date.
2. All Flock platform event-log entries — of any event type — referencing University of the Pacific (CA) 
as a receiving organization, sharing partner, or otherwise associated entity, between January 1, 2026 and 
the date of this request. Item 2 of W012570-041926 produced two such events; this request seeks any 
further events of any type (create, update, modify, permission change, delete, or otherwise) for that same 
entity and period.
3. Records reflecting the termination, deletion, modification, or end of the networkShare with 
permissions "feedView" created on 2026-02-12 (Event ID 7ede5f4e-4f97-56dc-9357-4b92d3904374) — 
including any platform event-log entry, configuration change record, communication, or other indication 
that the share was ended or its permissions altered. If no such records exist, please indicate whether this 
means:
(i) the share was terminated but the termination was not captured in the platform event log;
(ii) the share remains active; or
(iii) the Feb 12 create event and the Feb 28 delete event refer to the same networkShare whose 
permissions were modified between those dates — in which case, the records reflecting that modification 
are responsive to this item.
4. Any documentation describing the meaning and scope of the Flock platform's networkShare 
permission types — specifically "feedView," "Search," "VMS," and "Hotlist" — including what data 
access, query capability, or live-feed visibility each grants to a receiving organization. Vendor 
documentation, help-center articles, administrator guides, or platform reference materials in SMPD's 
possession are responsive.
Anticipated exemption issues:
* Civil Code § 1798.90.55(b) (via Gov. Code § 7927.705). The records requested describe sharing-
configuration metadata — share identifiers, permission scopes, lifecycle events, and vendor 
documentation — not "ALPR information" as defined in § 1798.90.5(c) (information or data collected 
through use of an ALPR system). § 1798.90.55(b)'s restriction operates against disclosure of ALPR 
information itself; it does not exempt records documenting the configuration of sharing relationships. 
SMPD's production under W012570-041926 included configuration metadata of this exact type.

remaining responsive events.

1. provide specific exemption citations per Gov. Code § 7922.540;
2. identify the withheld record type and volume;
3. indicate whether the denial rests on a claim that the records are held by Flock Safety rather than 
SMPD; and
4. if the denial invokes Civil Code § 1798.90.55(b) or any similar provision, explain how that provision 
applies to sharing-configuration metadata that does not contain ALPR information as defined by § 
1798.90.5(c).
