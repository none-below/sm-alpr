Record(s) Requested: Pursuant to the California Public Records Act (Gov. Code § 7920.000 et seq.), I 
request the following records from the San Mateo Police Department. This request seeks existing records 
only (Gov. Code § 7922.530; Sierra Club v. Superior Court (2013) 57 Cal.4th 157).
Context
As you are aware, SMPD Policy 463, section 463.10 (ALPR Data Search Audits) provides that the ALPR 
data search audit "shall be documented in the form of an internal department memorandum to the Chief 
of Police," and that "[a]fter review by the Chief of Police, the memorandum and any associated 
documentation shall be filed and retained."
Gov. Code § 7922.570(a) provides that an agency shall make information available in any electronic 
format in which it holds the information.
Scope
For clarity, this request does not seek the memorandum files already produced under W012461-040226 
or W013260-081726, and those files are excluded from it. The items below seek different categories of 
record: the transmittals by which the memoranda were sent to the Chief of Police and the memoranda as 
they existed at the time of transmittal, the native word-processing files as currently held, prior versions, 
and system-maintained version history.
Records requested — covering December 2025 through the date of production
1. For each monthly ALPR audit memorandum prepared under Policy 463.10, the email or other record

by which the memorandum was transmitted to the Chief of Police, together with the memorandum as 
attached or enclosed at the time of that transmittal. If any memorandum was delivered other than by 
email, the record reflecting that delivery.
2. Records reflecting the Chief of Police's review of each memorandum described in item 1, and its 
subsequent filing and retention, with dates.
3. The native-format electronic file, as currently held by the Department, for each memorandum 
described in item 1. This item requests the word-processing files themselves, not PDF renderings.
4. Any prior, superseded, draft, or alternate version of any memorandum described in item 1, retained in 
any form or location, including versions retained in a document management system, cloud storage, 
network file share, email attachment, or local drive.
5. The version history, revision history, or file audit trail maintained by the system in which each 
memorandum described in item 1 is stored — for example, Microsoft 365, SharePoint, OneDrive, or a 
network file server — showing save events, dates, and the account associated with each.
6. Records sufficient to identify where the Policy 463.10 memoranda are filed and retained after the 
Chief of Police's review, including the system or repository name and the folder, library, or path used.
7. Any record reflecting a revision, correction, re-export, or re-issuance of any Policy 463.10 audit 
memorandum, including tasking, transmittal, review, or correspondence concerning such a change.
8. Any records retention schedule or policy the Department applies to the Policy 463.10 audit 
memoranda and their prior versions.
If no records are located for any individual item, please respond to that item separately and continue 
processing the remaining items. Each item is severable. If any single item requires additional processing 
time, please respond to the remaining items on the statutory timeline rather than extending the request 
as a whole.
If any portion is denied, please provide specific exemption citations per Gov. Code § 7922.540 and 
identify the withheld record type and volume. Exact copies of existing records are requested per Gov. 
Code § 7922.530(a); this request does not ask the Department to create any record that does not exist — 
where none exists, a statement to that effect is requested.
