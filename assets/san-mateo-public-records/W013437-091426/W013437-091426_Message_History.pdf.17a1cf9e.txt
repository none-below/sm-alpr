Pursuant to the California Public Records Act (Gov. Code § 7920.000 et seq.), I request the following 
records from the San Mateo Police Department.
This request seeks existing records only (Gov. Code § 7922.530; Sierra Club v. Superior Court (2013) 57 
Cal.4th 157).
Context
As you are aware, on September 2, 2026, in its determination on request W013308-082426, the 
Department produced a search-audit record for search ID 9920424e-bfd0-4f87-8423-6abce941fdc7 
(search time 03/05/2026, 10:15:07 PM UTC) in which the words "Homicide/Death" were redacted from 
the Reason field while the word "Investigation" was left visible. Government Code section 7922.540 
requires that a determination withholding any portion of a responsive record be in writing and state the 
exemption relied upon. No exemption was cited for that redaction and no redaction log or field-specific 
determination accompanied the production.

related content without redaction:

search ID eb6a27e9-e279-46dc-ac67-2a8453f5db49 (search time 12/04/2025, 12:18:51 AM UTC) reads

Records requested
1. Exemption basis for the September 2, 2026 redaction. The Government Code section 7922.540 
determination, or any other record reflecting the exemption relied upon, redaction log, review note, or 
exemption worksheet, for the redaction of "Homicide/Death" from the Reason field of the search-audit 
record for search ID 9920424e-bfd0-4f87-8423-6abce941fdc7, produced September 2, 2026 under request
W013308-082426. If no responsive record exists, please affirm the search performed.
2. Basis for treating Reason-field homicide references as exempt, or not. Any record reflecting a 
determination, standard, or criteria the Department applies to decide whether Reason-field content 
referencing a homicide or death investigation is exempt from disclosure under Government Code § 
7923.600 — including any record explaining why the Reason-field values identified above, in the 
Department's own productions of the December 2025 and February 2024 audit records (request 
W012541-041426) and the May 2026 audit record (request W012818-053026), were released without 
redaction, if the Department's position is that Reason-field content of that kind is generally exempt.
3. Correction, if any. If the Department's position is that the September 2, 2026 redaction was made in 
error, or alternatively that the Reason-field values identified above should also have been redacted, a 
written statement to that effect.
If no records are located for any individual item, please respond to that item separately and continue 
processing the remaining items.
Anticipated exemption issues
- Gov. Code § 7923.600. The records requested are records of the Department's own redaction and 
production decisions — exemption citations, redaction logs, review notes, and determinations — not 
investigatory files compiled in connection with any particular case.
- Segregability (Gov. Code § 7922.525(b)). If any individual record contains both responsive and exempt 
content, I request the reasonably segregable non-exempt portions after redaction.
If any portion is denied, please:
1. respond to that item separately and state the specific legal basis for the denial;
2. provide specific exemption citations per Gov. Code § 7922.540;
3. identify the withheld record type and volume; and
4. continue processing the remaining items.
