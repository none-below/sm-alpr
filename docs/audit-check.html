PDF revision & edit checker

Drop in a PDF to recover its hidden revision history. Many editors save changes as an incremental update appended to the file, leaving every earlier version inside it. This tool reconstructs each revision, fingerprints the tool that generated or edited each one (from the Producer string and the XMP toolkit), and diffs the text so deleted or altered content is recovered. A file that was re-rendered/flattened (“Print to PDF”) has no prior revisions to recover — it will show a single revision.

🔒 Everything runs in your browser. The PDF is never uploaded anywhere.

Paste a path from the repo (fetched from main via GitHub), a full URL, or add ?pdf=<path> (optionally &ref=<branch>) to this page’s address — so a reviewer opens the link and sees the result without re-uploading.

Notes: “EDITED / RE-SAVED” means a revision’s DocumentID differs from its InstanceID, or its modify date is later than its create date — signatures of a file opened and saved again after creation. Text diffs are whitespace-normalized, so pure layout reflow is ignored and only real content changes appear. Absence of recoverable revisions is not proof a file was never edited — a flattened re-render discards the prior versions.
